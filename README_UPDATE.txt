ОБНОВЛЕНИЕ JARVIS: управление окнами + синонимы + исправление ошибки сборки.

Как установить (GitHub):
1. Распакуйте архив.
2. В репозитории: Add file -> Upload files, выделите ВСЕ файлы из архива (кроме этого README) и перетащите.
3. Commit changes. Файлы с теми же именами заменятся, WindowManager.cs и SynonymStore.cs добавятся.
4. Дождитесь зелёной сборки во вкладке Actions и скачайте новый JARVIS.exe.
